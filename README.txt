RWANDA RIDE ROLE-BASED FRONT-END SYSTEM

Pages:
1. index.html — Login page
2. user-dashboard.html — Customer/User dashboard
3. owner-dashboard.html — Business Owner dashboard, based on the previous admin dashboard style
4. admin-dashboard.html — Super Admin dashboard with access/management areas for customers, owners, businesses and bookings
5. style.css — shared responsive styling
6. script.js — demo role-based login routing

DEMO LOGIN:
Customer: customer@rwandaride.com

For this prototype, any password works after selecting the matching role.

IMPORTANT:
This is a front-end prototype. For a real school/project system, connect the login to PHP/MySQL (XAMPP), hash passwords, store users and roles in a database, and enforce role permissions on the server.
